# مواصفات منصة محلات — الإصدار 4.0

وثيقة المتطلبات للمبرمج، مبنية من ملف المتطلبات المحدَّث (المراجعة `2026-10-05-final`). موقع ثابت: `index.html` و`assets/` في الجذر، ولا يحتاج Cloudflare Pages أمر بناء.

- **235 متطلباً** بقواعدها ومعايير قبولها، ولكل متطلب الصفحات التي تستعمله.
- **84 صفحة** للواجهات الأربع مع معاينة توضيحية لكل صفحة، وحالاتها المشتركة تُذكر مرة واحدة.
- 5 مخططات للرحلة، والحسابات والرسوم مع حاسبة المارت، و23 قيمة مرنة، و96 تقريراً، والربط والجودة.
- «ما تغيّر عن 3.3» و«مسائل للمالك» (161 مسألة تعارض أو غموض وجدتها مراجعة النص).
- `prd.md`: النسخة النصية الكاملة للقراءة بالأدوات.

الإصدار السابق (3.3 بعد قرارات المالك) محفوظ في الوسم `pre-v4`.

## البناء
```bash
cd tools
python build.py          # يكتب index.html وassets/ وprd.md في جذر المستودع
python verify4.py        # يقارن الموقع بملف المالك: المتطلبات والصفحات والإعدادات والتقارير
```
يحتاج Python 3 مع `beautifulsoup4` و`lxml`.

## المصدر والبيانات
| الملف | الدور |
|---|---|
| `tools/newprd.json` | بيانات ملف المالك (المتطلبات والصفحات والإعدادات والأمثلة والتقارير والمخططات). المصدر الوحيد للمحتوى |
| `tools/source/Mahallat-PRD.html` | ملف المالك الأصلي كما وصل |
| `tools/previews_raw.json` | معاينات الصفحات الـ84 مستخرجة من كود الملف الأصلي |
| `tools/qa/fixes.json` | التصحيحات اللغوية المطبَّقة (29 تعديلاً مسجلة في `edit_log.json`) |
| `tools/qa/notes.json` | مسائل المالك من مراجعة النص |
| `tools/lite/req_all.json` | متطلبات 3.3 للمقارنة في «ما تغيّر عن 3.3» |

لتحديث المحتوى: عدّل `newprd.json` ثم شغّل `build.py` و`verify4.py`.
