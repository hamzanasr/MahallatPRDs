# مهمة: إعادة صياغة عميقة لكتل نص في وثيقة متطلبات (منصة توصيل سعودية) — الجولة الثانية

الملف المدخل: JSON قائمة عناصر {"k": مفتاح, "s": القسم, "r": الدور, "h": نص HTML صغير}. الدور r: "rule" قاعدة في متطلب، و"accept" معيار قبول، و"other" جملة أو خلية في أقسام الوثيقة.
الملف المخرج: JSON كائن {مفتاح: النص المحرر}. اكتب المخرج بأداة Write في المسار المحدد، وتأكد أنه JSON صالح.

في الجولة الأولى تُرك كثير من الكتل لأنه "واضح". هذه الجولة أشد: **أعد كتابة كل كتلة فيها جملة أو أكثر** لتصير بعربية مبسطة ومهنية يفهمها المبرمج من أول قراءة.
اتركها دون تغيير فقط في الحالات التالية: (أ) اسم أو مصطلح أو قائمة مصطلحات مفصولة بـ «·» أو فواصل، (ب) عبارة قصيرة واضحة تمام الوضوح من ثلاث كلمات أو أقل، (ج) غموض لا يُحل من النص نفسه (فلا تخترع حلاً).

## قواعد إلزامية (يرفض الفحص الآلي أي خرق ويُبقي النص الأصلي)
1. لا تغيّر المعنى ولا القرارات. لا تضف قاعدة أو استثناءً أو رقماً أو شرطاً غير موجود، ولا تحذف شيئاً.
2. أبقِ كل رقم بالعدد نفسه من المرات (أرقاماً غربية 0-9)، وكل معرّف متطلب (ORD-003)، وكل كلمة لاتينية.
3. أبقِ كل نص بين « » حرفياً.
4. أبقِ وسوم HTML الموجودة بالعدد نفسه (<b> <bdi> <a> <span>…) ولا تضف وسوماً.
5. الطول بين 65% و150% من الأصل تقريباً.

## الأسلوب
- كل جملة تبيّن **من** يفعل **ماذا**، و**متى**، وتحت **أي شرط**، وما **النتيجة**. استبدل المبني للمجهول الغامض بفاعل صريح إن كان الفاعل معروفاً من النص أو السياق (العميل، التاجر، المندوب، السائق، المدير، الدعم، النظام).
- اقسم الجملة الطويلة إلى جمل قصيرة، واجعل كل جملة فكرة واحدة.
- احذف الحشو والتعليقات الإنشائية والصفات المبهمة («مرن جداً»، «بسهولة»، «أي ميزة»). لا تضف وعوداً.
- فصحى مبسطة، لا ثقيلة ولا دارجة، بلا ترجمة حرفية.
- الدور accept: اكتبه نتيجةً قابلة للتحقق بصيغة «عند ... يحدث ...» أو «... لا ...»، مع الاستثناء المهم إن ذُكر في النص.
- الدور rule: جملة قاعدة مباشرة بفعل واضح («يلغي العميل ...»، «يُحسب ...»).
- الخلايا (other) في الجداول: اجعلها جملة أو عبارة تامة المعنى دون تكرار عنوان العمود.

## المصطلحات الموحدة
- الطلب / المهمة (إسناد الطلب لمندوب) / الرحلة (حتى 3 مهام). الحجز (على البطاقة) / التحصيل (عند الاكتمال) / الاسترداد.
- نسبة العقد (لا «عمولة» إلا اسم بند)، رسوم الخدمة، رسم الدفع، رسم ميسر الفعلي.
- «واجهات المنصة»، «لوحة الإدارة»، «يُعرض الطلب على المندوب»، «نطاق الـ100 متر» (مسافة لا تتجاوز 100 متر بين موقع المندوب والنقطة المحددة).
- «مرن» = قيمة في إعدادات لوحة الإدارة يعدّلها المسؤول المخوّل دون إصدار نسخة جديدة.

## مثال
- قبل (accept): إغلاق التطبيق لا يوقف العداد
  بعد: إذا أغلق العميل التطبيق أثناء مهلة الـ60 ثانية يستمر العداد ولا يتوقف.
- قبل (rule): تنبيه للمندوب قبل انتهاء مدة التحضير بـ5 دقائق ليتجه للاستلام
  بعد: ينبّه النظام المندوب قبل انتهاء مدة التحضير بـ5 دقائق ليتجه إلى المتجر للاستلام.
- قبل (other): زر «الطلب جاهز للاستلام» لا يعمل قبل إرفاق الفاتورة
  بعد: لا يستطيع التاجر الضغط على زر «الطلب جاهز للاستلام» قبل أن يرفق فاتورة المنتجات.

اكتب في ردك سطراً واحداً: عدد العناصر المدخلة وعدد التي أعدت كتابتها.
